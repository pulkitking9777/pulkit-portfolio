# PULKIT OS — React + Vite Portfolio

## Requirements
- Install Node.js (LTS) from https://nodejs.org/
- Install VS Code.

## Run the project
1. Extract this ZIP.
2. Open the `pulkit-os-react` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL Vite prints in the terminal (usually `http://localhost:5173`).

## Build for deployment
```bash
npm run build
```
Vite creates the production site in the `dist` folder.

## Personalize before publishing
- Replace `your-email@example.com` in `src/App.jsx` with your public email.
- Update your project statuses and achievement records to match reality.
- Add your resume PDF and connect a download link if you have one.
- The current portfolio is frontend-only: it does not yet have a database, admin login, or upload system.

## Main files
- `src/App.jsx`: React components and editable content data
- `src/index.css`: responsive dark/electric-blue design
- `src/main.jsx`: React entry point
- `package.json`: dependencies and commands
